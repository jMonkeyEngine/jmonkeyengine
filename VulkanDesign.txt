
function update:
    await: previous render on same frame
    reset command pool
    for each appstate:
        update appstate
    for each spatial:
        update controls
        update geometric state
    acquire render workers
    await: acquire swapchain image
    parallel for each viewport:
        renderViewPort
    submit rendering command buffers

function renderViewPort:
    cull geometries1
    async: compile globals
    parallel: for each geometry:
        render controls
        compile geometry settings to pipeline state
            * RenderState
            * shaders
            * uniform layout
            * push constants layout
            * specialization constants
            * dynamic states
        batch geometry by pipeline state
    for each batch: async: build pipeline
    sort batches
    allocate sequential batches evenly to workers
    parallel: for each worker:
        for each allocated batch (unordered):
            for each geometry: update descriptor sets
            sort batch
        start command buffer
        for each allocated batch (ordered):
            await: get globals
            await: get pipeline
            bind pipeline
            for each geometry (ordered):
                bind globals
                bind descriptor sets
                bind vertex buffers
                set push constants
                set dynamic properties
                render mesh
        end command buffer
        add semaphores to command buffer
